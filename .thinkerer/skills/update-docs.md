# Update docs

- **README.md:** shipped behaviour only, precise and verified. Update the relevant table or section
  (tabs, safety model, agent limits, tests, known limitations). Remove statements that became false.
  Plain language, no marketing.
- **docs/ROADMAP.md:** tick criteria you verified; update status.
- **docs/PRODUCT.md:** only if a product decision changed (ask the user; don't decide product alone).
- **AGENTS.md / skills:** if you found a rule or a repeated procedure missing, add or fix it.
  Keep AGENTS.md short (it's in every run's context); detail goes in a skill.
- `docs/THINKERER_MVP_v0.1.md` is historical: never edit.
